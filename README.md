# Zomato Restaurant Analysis — SQL Server & Power BI

## Project Overview
This project analyzes Zomato restaurant data using SQL Server and Power BI to explore restaurant distribution, ratings, customer votes, pricing, and online ordering and table booking availability.

## Tools & Technologies
- SQL Server — data analysis and SQL queries
- Power BI Desktop — interactive dashboard development
- Power Query — data cleaning and transformation
- DAX — measures and calculations
