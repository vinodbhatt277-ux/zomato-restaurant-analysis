# Zomato Restaurant Analysis --- SQL Server & Power BI

## Project Overview

This portfolio project explores restaurant distribution, ratings,
customer votes, pricing, online ordering, and table-booking availability
using SQL Server and Power BI. The aim is to demonstrate a practical
workflow from data preparation and SQL analysis to interactive reporting
and business-focused interpretation.

## Business Questions

The analysis explores questions such as:

-   How are restaurants distributed across locations and restaurant
    categories?
-   How do restaurant ratings, customer votes, and average cost vary?
-   Which locations and restaurants stand out on selected performance
    measures?
-   How do online ordering and table-booking availability vary across
    restaurants?
-   What patterns can be explored by comparing cost, ratings, votes, and
    restaurant characteristics?

These are analytical areas covered by the project; specific conclusions
should be drawn from the dashboard and underlying data rather than
assumed in advance.

## Tools & Technologies

-   **SQL Server** --- data exploration and analytical queries
-   **Power BI Desktop** --- interactive dashboard development
-   **Power Query** --- data cleaning and transformation
-   **DAX** --- measures and calculations

## Workflow Demonstrated

1.  Prepared and transformed data for analysis.
2.  Used SQL queries to explore restaurant performance and answer
    analytical questions.
3.  Created DAX measures for key metrics, including restaurant counts,
    average ratings, votes, and average cost.
4.  Built a three-page interactive Power BI dashboard with visuals and
    slicers.
5.  Used the dashboard to explore patterns that may inform restaurant
    performance and customer-preference decisions.

## Key Findings and Business Recommendations

Use the dashboard to identify findings that are directly supported by
the data---for example, location-level differences, rating and vote

Recommendations should follow from those verified findings. This README
intentionally avoids stating specific numerical conclusions that have
